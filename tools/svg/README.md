# Рисунок геймпада

`assets/apex5.svg` собирается из линейного рисунка Apex 5 на док-станции с сайта Flydigi Space Station.
Исходник в репозиторий не кладётся, его нужно скачать:

```bash
curl -o tools/svg/gamepad-dock.svg https://space_station.flydigi.com/assets/gamepad-dock-TuhF65hu.svg
```

Имя файла содержит хеш сборки сайта и может смениться. Тогда новое имя ищется в JS-бандле страницы
по строке `gamepad-dock`.

Сборка (Python 3.11+):

```bash
python -m venv tools/svg/.venv
tools/svg/.venv/bin/pip install -r tools/svg/requirements.txt
tools/svg/.venv/bin/python tools/svg/build.py
```

## Что делает `build.py`

- Убирает док, подсветку нажатой B и фон, обрезает viewBox до геймпада.
  Координаты остаются в пространстве исходника 984×680, как и в `src/ui/pad.rs`.
- Пересобирает линии как настоящие stroke (`stroke.py`). В исходнике каждая линия — залитый контур.
  По контуру находится осевая линия, подгоняются кривые Безье, а каждая линия проверяется:
  её край должен совпадать с исходным контуром (в среднем 0,013 единицы, максимум 0,025).
  Буквы, логотип, иконки View/Menu и шкалы регуляторов остаются заливками.
- Строит зоны кнопок: корпус, бамперы, триггеры, четыре направления крестовины, круглые кнопки.

## Структура SVG

| Слой | Содержимое |
|---|---|
| `#body-fill` | заливка корпуса |
| `#keys` | зоны кнопок `.key` (прозрачные), группы с `id` и `data-key` |
| `#lines-hi` (`.ln-hi`, прозрачность 0,58) | контур корпуса, бамперы и триггеры |
| `#lines` (`.ln`, прозрачность 0,42) | остальные линии |

Прозрачность линий задана на слоях, поэтому пересечения не становятся ярче.
Толщины линий — классы `.hair` `.thin` `.mid` `.reg` `.bold` (0,31–1,78).

`data-key` — номер кнопки, как в `src/ui/pad.rs`:

| id | data-key | id | data-key |
|---|---|---|---|
| `dpad-up` `dpad-right` `dpad-down` `dpad-left` | 0 1 2 3 | `lb` `rb` | 10 11 |
| `a` `b` | 4 5 | `lt` `rt` | 12 13 |
| `view` | 6 | `ls` `rs` | 14 15 |
| `x` `y` | 7 8 | `home` | 27 |
| `menu` | 9 | | |

У линий кнопок (`a-ln`, `ls-cap`, `logo`…) тот же `data-key`, что и у их зон.
Задних кнопок (M1–M4, LM, RM) на рисунке нет: это вид спереди.
