# Рисунок геймпада

`assets/apex5.svg` собирается из линейного рисунка Apex 5 на док-станции с сайта Flydigi Space Station.
Исходник в репозиторий не кладётся, его нужно скачать:

```bash
curl -o tools/svg/gamepad-dock.svg https://space_station.flydigi.com/assets/gamepad-dock-TuhF65hu.svg
```

Имя файла содержит хеш сборки сайта и может смениться. Тогда новое имя ищется в JS-бандле страницы
по строке `gamepad-dock`.

Сборка (Python 3.11+):

```bash
python -m venv tools/svg/.venv
tools/svg/.venv/bin/pip install -r tools/svg/requirements.txt
tools/svg/.venv/bin/python tools/svg/build.py
```

## Что делает `build.py`

- Убирает док, подсветку нажатой B и фон.
  Координаты остаются в пространстве исходника 984×680, как и в `src/ui/pad.rs`.
- Пересобирает линии как настоящие stroke (`stroke.py`). В исходнике каждая линия — залитый контур.
  По контуру находится осевая линия, подгоняются кривые Безье, а каждая линия проверяется:
  её край должен совпадать с исходным контуром (в среднем 0,013 единицы, максимум 0,025).
  Буквы, логотип, иконки View/Menu и шкалы регуляторов остаются заливками.
- Строит зоны кнопок: четыре направления крестовины и круглые кнопки.
- Добавляет плечевые и задние кнопки (LT, LB, LM, RT, RB, RM, M1–M4) отдельными плашками вокруг геймпада.
  Их формы и расположение взяты со страницы подсветки Flydigi Space Station и записаны прямо в `build.py`.
  Плашки привязаны к габаритам корпуса и равномерно масштабированы. Правые зеркалят левые.
  Задние кнопки опущены так, чтобы не касаться корпуса.
- Размечает подсветку: полосу по нижнему краю, между нижним швом и контуром корпуса, и пластину FLYDIGI на левой рукоятке.
  Светодиоды (10 под полосой и 2 под пластиной) расставлены по фото разобранного геймпада.
  Фото совмещено с рисунком по центрам стиков, светодиоды полосы выровнены симметрично.
  Два светодиода полосы на фото не видны: один под шаровой опорой правого стика, второй — его зеркальная пара.
  Это кружки с `data-led` в `#leds`. Какой цвет блока подсветки идёт на какой светодиод, задано в `src/ui/pad.rs`.

viewBox охватывает геймпад с плашками. Сам геймпад без плашек записан в атрибуте `data-pad-view`:
его приложение показывает там, где плашки не нужны.

## Структура SVG

| Слой | Содержимое |
|---|---|
| `#body-fill` | заливка корпуса |
| `#keys` | зоны кнопок `.key` (прозрачные), группы с `id` и `data-key` |
| `#lines-hi` (`.ln-hi`, прозрачность 0,58) | контур корпуса, бамперы и триггеры |
| `#lines` (`.ln`, прозрачность 0,42) | остальные линии, в том числе линия подсветки `led-strip` и пластина `led-plate` |
| `#leds` | зона пластины FLYDIGI `led-plate-area` и точки светодиодов `data-led="strip"` / `"plate"` (прозрачные) |
| `#tiles` | плашки `.tile` с `id` и `data-key`, подписи `<text>` с тем же `data-key` |

Прозрачность линий задана на слоях, поэтому пересечения не становятся ярче.
Толщины линий — классы `.hair` `.thin` `.mid` `.reg` `.bold` (0,31–1,78).

`data-key` — номер кнопки, как в `src/ui/pad.rs`:

| id | data-key | id | data-key |
|---|---|---|---|
| `dpad-up` `dpad-right` `dpad-down` `dpad-left` | 0 1 2 3 | `lb` `rb` | 10 11 |
| `a` `b` | 4 5 | `lt` `rt` | 12 13 |
| `view` | 6 | `ls` `rs` | 14 15 |
| `x` `y` | 7 8 | `m1` `m2` `m3` `m4` | 18 19 20 21 |
| `menu` | 9 | `lm` `rm` | 22 23 |
| `home` | 27 | | |

У линий кнопок (`a-ln`, `ls-cap`, `logo`…) тот же `data-key`, что и у их зон.
Бамперы и триггеры на корпусе (`lb-ln`, `lt-ln`…) остаются просто линиями, кнопки для них — плашки.
